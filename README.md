# シンクロ・タップ（SYNC TAP）

1人から10人まで。同じ部屋で、それぞれのスマホを持って遊ぶリアルタイム同期タップゲーム。
画面の指示に合わせて全員が「いっせーの」で操作する。ひとりでもズレたら失敗。

## 遊び方

1. 1人が「ルームを作る」を押すと4桁のコードが出る
2. 参加する人が同じURLを開き、その4桁を入力して参加
3. 全員そろったらホストが「ゲーム開始」

指示は4種類。ラウンドが進むほど速く、判定も厳しくなる。ミス5回で終了。
リザルトでひとりずつの平均ズレが出る。

| 指示 | やること |
|---|---|
| タップ | 全員同時にタップ |
| あなただけ | 指定された1人だけタップ。他は触ったら失敗 |
| ←↑↓→ | 全員が同じ方向にスワイプ |
| さわるな | 誰も触らない（フェイント） |

## 仕組み

- **サーバー不要。** 公開MQTTブローカー（WebSocket）を中継に使う。3経路を自動フェイルオーバー
- **時計同期**：Cristian法でホスト端末との時計ズレを推定。ロビーに精度を表示
- **決定論的な進行**：seedとラウンド番号から各端末が指示を独立に計算するので、毎ラウンドの通信が要らない。通信遅延は判定精度に影響しない
- **PWA**：ホーム画面に追加するとアプリのように起動する。更新はService Workerが自動で配る

## 調整するところ

`app.js` の冒頭にまとまっている。

| 定数 | 現在値 | 意味 |
|---|---|---|
| `LIVES` | 5 | ミス可能回数 |
| `WIN_BASE` | 200ms | 成功と認める最大ズレ（初期値） |
| `WIN_OF(i)` | 200 − 2.2×i（下限85ms） | ラウンドが進むほど判定を厳しく |
| `intervalOf(i)` | 2000 − 35×i（下限520ms） | ラウンド間隔 |
| `instructionOf()` | タップ40% / ひとりだけ25% / スワイプ20% / さわるな15% | 指示の出現比率 |

`BUILD` はバージョン表示。更新したら書き換えると、タイトル画面下で反映を確認できる。

## 開発

`dev/` に検証用の道具が入っている（デプロイ対象外）。

```bash
npm i playwright ws            # 初回のみ
node dev/server.js             # ローカルサーバー + 検証用MQTTブローカー
node dev/test.js               # ブラウザ3つで自動プレイして通し確認
J=2 node dev/test.js           # 入力ブレを大きくして（ふつうの3人を想定して）確認
node dev/make-icons.js         # アイコン再生成
```

`dev/server.js` はこのリポジトリのルートを配信する想定。パスは環境に合わせて調整すること。

## デプロイ

ホーム画面に追加済みの端末もそのまま最新版になる。
